# Хрестики-нулики — Нескінченне поле
### Tic-Tac-Toe on an Infinite Board — Windows Forms (.NET 8)

---

## Умови перемоги / Win condition
**5 символів поспіль** (по горизонталі, вертикалі або діагоналі) — класичні правила Гомоку.

---

## Збірка / How to build

**Потрібно:** .NET 8 SDK для Windows.  
Download: https://dotnet.microsoft.com/download/dotnet/8.0

```bat
cd TicTacToe
dotnet build
dotnet run
```

Або відкрийте `TicTacToe.csproj` у Visual Studio 2022+ і натисніть **F5**.

## Режими гри

| Режим | Опис |
|---|---|
| **Гравець проти комп'ютера** | Комп'ютер грає за ✖ і ходить першим. Ви — ◯. |
| **Гравець проти гравця** | Два гравці по черзі на одному екрані. |

Перемикання: кнопка **«Нова гра»** → вибір режиму з меню.

## Алгоритм ШІ

Комп'ютер робить **перший хід** у центрі поля.  
На кожному ходу:

1. **Миттєва перемога** — якщо є хід, що завершує 5 в ряд, робить його.
2. **Блокування** — якщо суперник може виграти наступним ходом, блокує.
3. **Евристичне оцінювання** — для кожної кандидатної клітинки рахується:
   - власна «атакова» оцінка (кількість і довжина відкритих рядів)
   - мінус половина найкращої відповіді суперника (1 хід уперед = **lookahead 2 ply**)
4. Обирає хід з максимальним сумарним балом.
